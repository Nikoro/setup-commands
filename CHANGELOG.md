# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-06

### Added
- Initial release of Setup Commands CLI GitHub Action
- Automatic Dart pub-cache PATH configuration
- `ref` input parameter to support pinning specific Git references (tags, branches, or commits)
- Automatic resolution of latest release tag when ref not specified
- Fallback to main branch when no releases are available
- Comprehensive README documentation with usage examples
- Support for dart-lang/setup-dart integration
- Troubleshooting guide and example workflows
